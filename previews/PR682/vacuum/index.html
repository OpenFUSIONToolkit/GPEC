Vacuum

Vacuum computes the magnetostatic response of the region between the plasma boundary and a conducting wall, or of free space when there is no wall, following Chance (1997) and Chance et al. (2007). It runs inside ForceFreeStates whenever vac_flag = true, and its matrices are shared with PerturbedEquilibrium.

What it computes

For a normal displacement $\xi$ of the plasma boundary, expanded in the poloidal harmonics of the run, the perturbed vacuum field is found from a Green's-function integral over the boundary and the wall, and the vacuum energy is the quadratic form $\delta W_v = \xi^\dagger W_v \xi$. $W_v$ is the vacuum part of the free-boundary energy, $W = W_\mathrm{plasma} + W_\mathrm{vacuum}$, whose eigenvalues decide the ideal kink stability on the Stability page: a close conducting wall raises $W_v$ and stabilizes external modes, no wall gives the free-space limit. ForceFreeStates scales wv by the resonance factors $(m - nq)(m' - nq)$ of its row and column harmonics, the convention of Chance (1997), before adding it to the plasma energy; compute_vacuum_response returns it unscaled. When the run needs it, the module also returns the vacuum surface-current matrix $I_v$, which PerturbedEquilibrium inverts into the surface inductance $L$ of the plasma response.

Running it

The wall is the optional [Wall] section of the deck; omit it for no wall. shape selects one of five shapes, each with its own keys, and equal_arc_wall (default true) distributes the wall nodes by equal arc length:

# one [Wall] section per deck; the five shapes:
[Wall]
shape = "conformal"       # the plasma boundary expanded by standoff_fraction minor radii
standoff_fraction = 0.3

[Wall]
shape = "elliptical"      # an ellipse of the given minor radius
minor_radius = 0.3

[Wall]
shape = "dee"             # a D-shaped wall: standoff_fraction, half_thickness, elongation, center_offset, triangularity, corner_sharpness
standoff_fraction = 0.3
elongation = 1.5
triangularity = 0.5

[Wall]
shape = "mod_dee"         # the same shape placed by minor_radius instead of standoff_fraction
minor_radius = 0.3

[Wall]
shape = "file"            # a wall contour read from a file
file = "wall.dat"

examples/Solovev_ideal_example holds a near-marginal kink by a conformal wall; the DIII-D-like examples run without one. In a script the shapes are ConformalWall, EllipticalWall, DeeWall, ModDeeWall and FileWall, passed as the wall keyword of the solve (nothing for no wall), and the response itself is

using GeneralizedPerturbedEquilibrium

inputs = Vacuum.VacuumInput(eq, 0.995, 256, 1, 1:10, [1])   # the surface at ψ_N = 0.995: mtheta, nzeta, m_modes, n_modes
vac = Vacuum.compute_vacuum_response(inputs, Vacuum.ConformalWall(; standoff_fraction=0.3); compute_Iv=true)
vac.wv, vac.I_v, vac.plasma_pts, vac.wall_pts            # I_v is zero unless compute_Iv=true

with eq a PlasmaEquilibrium; VacuumInput(; x, z, ν, mtheta_in, m_modes, n_modes, mtheta, nzeta) takes a boundary given point by point instead, where ν(ψ, θ) is the toroidal-angle offset of the straight-field-line coordinates, $\phi = 2\pi\zeta + \nu$ with $\phi$ the internal toroidal angle of the Conventions Reference (the laboratory angle carries the helicity sign). With [ForceFreeStates] nzeta_vacuum > 1 the response is evaluated on a toroidal grid, with the singular correction of the 3D kernel (examples/Solovev_ideal_example_3D).

Numerical notes

  • The Legendre functions of the Green's function are evaluated from Bulirsch's elliptic integrals, and by 32-point Gaussian quadrature for large arguments ($n\hat\rho \geq 0.1$).
  • For n = 0 with a closed wall the kernel is regularized automatically.
  • Close walls: plasma–wall rows are integrated about the closest point of the source surface, so the wall's node placement (equal_arc_wall, wall files, a revolved wall with ν ≠ 0) does not matter. Both use Gauss nodes on the sinh map of [Johnston & Elliott, Int. J. Numer. Meth. Engng 62 (2005) 564], which follows the kernel peak over the gap: in 2D on ±6 node intervals about the closest point, in 3D radially in the polar patch centred at the closest point. Rows more than 4 source node spacings from the source take the plain trapezoidal rule. $W^v$ keeps its far-wall convergence down to gaps of a few hundredths of a node spacing; a wall touching the plasma is rejected. Each observer uses its single closest point, so a wall close to two separate parts of the plasma is treated only at the nearer one.

GeneralizedPerturbedEquilibrium.Vacuum.StellSymBasis — Type
StellSymBasis

Unitary change of basis U for residue class k making U†D̂ₖU real, and block-diagonal when the class is self-conjugate. Both Laplace kernels depend only on |r_obs − r_src| and n_src·(r_obs − r_src), so a stellarator-symmetric boundary gives

D̂ₖ[σp, σq] = ω^{k(a_p − a_q)} · conj(D̂ₖ[p, q]),   ω = exp(-2πi/nfp),

with σ the within-period reflection (θ, ζ) → (−θ, −ζ) and a_p = 0 on the ζ = 0 plane, 1 elsewhere. Pairing p with σp into a symmetric and an antisymmetric column makes the result real; a self-conjugate class (is_self_conjugate) has real D̂ₖ and splits by the sign of ω^{k a_p}.

Fields

  • σ_map: σ as a grid-index map of 1:num_points_per_fp
  • σ_phase: ω^{k a_p}, relating a pair's two operator rows
  • pair_reps: one grid index per reflection pair (partner is σ_map[p])
  • columns, pair_columns: basis columns, and the range each pair contributes
  • block_sizes: columns per surface in each block (length is 1 or 2)

GeneralizedPerturbedEquilibrium.Vacuum.WallSettings — Type
WallSettings

Abstract supertype of the vacuum wall shapes: ConformalWall, EllipticalWall, DeeWall, ModDeeWall and FileWall. A run with no wall has no WallSettings at all; the wall is nothing, and the deck omits its [Wall] section.

GeneralizedPerturbedEquilibrium.Vacuum._compute_vacuum_response_3d! — Method
_compute_vacuum_response_3d!(vac_data, inputs, wall_settings; compute_Iv=false)

3D (inputs.nzeta > 1) vacuum response via block-circulant field-period reduction.

The nfp-periodic boundary makes the layer operators block-circulant in the field-period index, so the problem block-diagonalizes by toroidal residue class k = mod(n, nfp):

D̂ₖ = Σ_d D_d ω^{k d},   Ŝₖ = Σ_d S_d ω^{k d},   ω = exp(-2πi/nfp),

with D_d, S_d coupling observers in field period 0 to sources in period d. Each class is one solve wv[k] = (4π²/M)·Ẽᴴ·(D̂ₖ \ Ŝₖ)|_plasma·Ẽ, the 3D analogue of the 2D loop over decoupled n. The phase sum is folded into the kernel write, so only the reduced operator is stored.

Real D_d, S_d give D̂₋ₖ = conj(D̂ₖ), so class mod(nfp - k, nfp) reuses this factorization with a conjugated mode basis. A stellarator-symmetric boundary gets a StellSymBasis, making the class operator real and splitting a self-conjugate class into two half-size blocks.

compute_2D_kernel_matrices!(grad_greenfunction, greenfunction, observer, source, n)

Compute kernels of integral equation for Laplace's equation in a torus. WARNING: This kernel only supports closed toroidal walls currently. The residue calculation needs to be updated for open walls.

Arguments

  • grad_greenfunction: Gradient Green's function matrix (output)
  • greenfunction: Green's function matrix (output)
  • observer: Observer geometry struct (PlasmaGeometry or WallGeometry)
  • source: Source geometry struct (PlasmaGeometry or WallGeometry)
  • n: Toroidal mode number

Returns

Modifies grad_greenfunction and greenfunction in place. Note that greenfunction is zeroed only when the source is plasma; grad_greenfunction is not zeroed since it fills a different block of the (2 * mtheta, 2 * mtheta) depending on the source/observer.

Notes

  • Same surface: Simpson's rule away from the singular point, Gaussian quadrature on the panels about it, with analytical singularity removal [Chance Phys. Plasmas 1997 2161]
  • Plasma–wall rows within NEAR_GAP node spacings of the source curve: Simpson's rule plus sinh-graded Gauss nodes about the closest source point (add_near_window!), so the wall's node placement does not matter
  • Other plasma–wall rows: periodic trapezoidal rule, as in 3D (error ∝ exp(-2πd/h), see NEAR_GAP)

GeneralizedPerturbedEquilibrium.Vacuum.compute_3D_kernel_matrices! — Function
compute_3D_kernel_matrices!(grad_blocks, green_blocks, observer, source, PATCH_RAD, RAD_DIM, INTERP_ORDER, phases, sym_basis=nothing)

3D single- and double-layer kernels with Malhotra's polar singular correction (PPCF 62 (2020) 024004).

Far field: trapezoidal rule. Near field (kernel_row!, add_near_correction!): polar quadrature blended by a partition of unity, on source data upsampled 2× by trigonometric interpolation, about the observer on Gauss radial nodes, or for a plasma–wall row about the closest source point on sinh-mapped ones. Plasma–wall rows more than NEAR_GAP source node spacings away keep the trapezoidal rule alone, as in 2D.

A source in field period d is accumulated onto the period-0 column with weight phases[d+1], so the block-circulant reduction is written in and the full-torus source blocks are never stored. phases = [1.0] is the single-period (real) case.

grad_blocks is ∇_{x_src} φ · n_src; green_blocks is φ, filled only when source is the plasma (Chance 1997 eqs. 26–27). sym_basis evaluates one point per reflection pair and emits the real reduced operator; omit it for the untransformed matrix.

GeneralizedPerturbedEquilibrium.Vacuum.expand_field_periods — Method
expand_field_periods(inputs::VacuumInput) -> VacuumInput

Reconstruct the full-torus boundary from a single field period using the device field periodicity. When inputs.nfp > 1 (and the boundary is 3D), the input x, y, z arrays describe one field period spanning ζ ∈ [0, 2π/nfp) on an mtheta_in × nzeta_in grid; the full torus is generated by nfp rigid rotations about the Z-axis by 2π·k/nfp. The toroidal counts nzeta_in and nzeta are scaled to their full-torus totals and nfp is reset to 1, so all downstream code operates on the full surface unchanged.

The result is identical (to floating point) to passing the whole torus directly.

Returns inputs unchanged for axisymmetric (nzeta_in == 1) or single-period (nfp <= 1) cases.
