Forcing Terms

ForcingTerms specifies the external magnetic perturbation that drives the perturbed equilibrium: the spectrum of the normal field on the control surface at psilim, given either as a file of (m, n) amplitudes or computed by Biot–Savart from coil geometry. The [ForcingTerms] section is read when [PerturbedEquilibrium] runs; its result is the RMPField that perturbed_equilibrium applies to the plasma response.

Normalization

Internally every forcing is the unit-norm flux spectrum $\Phi_x$, the Fourier amplitude of $2\pi R\,(B_R\,\partial Z/\partial\theta - B_Z\,\partial R/\partial\theta)$ over the unit-norm angles $\theta, \zeta \in [0, 1]$, the quantity the Fortran GPEC calls Phi_x. A forcing file declares its own normalization by a tag; a coil set needs none, because the Biot–Savart pipeline produces $\Phi_x$ directly.

TagQuantityUnitsOn load
"normal_field_T" (default)Fourier modes of $B\cdot\hat n$ over $\theta \in [0, 2\pi]$Tweighted by the area element $J\lvert\nabla\psi\rvert$ and projected onto every harmonic of the run; a poloidally varying weight mixes modes, so the file must cover its sidebands (a warning asks for a wider m range when an edge harmonic carries more than 10% of the flux)
"sfl_flux_Wb"the straight-field-line flux $R\,(B_R\,\partial Z/\partial\theta - B_Z\,\partial R/\partial\theta)$ over $\theta \in [0, 2\pi]$T·m²multiplied by $(2\pi)^2$
"unit_flux"$\Phi_x$ itself, as a run records its forcing for replayT·m²loaded as is

File formats

ASCII (forcing_data_format = "ascii"): an optional # normalization: <tag> line, comment lines starting with #, and one n m real(amplitude) imag(amplitude) row per mode; all four columns are required:

# normalization: normal_field_T
1  6  1.0e-4  0.0
1  7  5.0e-5  2.0e-5

HDF5 (forcing_data_format = "hdf5"): datasets n, m, amplitude_real and amplitude_imag, all required, with the optional root attribute normalization:

using HDF5
h5open("forcing.h5", "w") do f
    f["n"] = [1, 1, 1]
    f["m"] = [5, 6, 7]
    f["amplitude_real"] = [1e-4, 2e-4, 1e-4]
    f["amplitude_imag"] = [0.0, 0.0, 0.0]
    HDF5.attrs(f)["normalization"] = "normal_field_T"
end

Coils

forcing_data_format = "coil" computes the field from coil geometry: the plasma boundary is sampled on an mtheta_coil × nzeta_coil grid, the Biot–Savart field of every coil set is evaluated there, projected onto the normal flux and Fourier decomposed. The toroidal angle of each observation point includes the straight-field-line offset $\nu(\psi, \theta)$ and the helicity $\mathrm{sign}(B_T)\,\mathrm{sign}(I_p)$ of the equilibrium, without which the decomposition would be wrong. Each [[ForcingTerms.coil_set]] block supplies one coil set, selected by source; shifts and tilts (shiftx/y/z, tiltx/y/z, n_tilt, …) apply to every source, which is what the Error Fields stage sweeps. From examples/DIIID-like_ideal_example/gpec.toml (the first block) and the other sources:

[ForcingTerms]
forcing_data_format = "coil"
machine = "d3d"
mtheta_coil = 480
nzeta_coil = 32

# ASCII .dat file, resolved to {dat_dir}/{machine}_{name}.dat
[[ForcingTerms.coil_set]]
name = "c"
currents = [1000.0, 500.0, -500.0, -1000.0, -500.0, 500.0]

# HDF5 file; `name` selects one set of a multi-set file
[[ForcingTerms.coil_set]]
source = "file"
h5_file = "/path/to/my_coils.h5"
name = "il"
currents = [1e4, 1e4, 1e4, 1e4, 1e4, 1e4]

# Analytic PF hoop; a tilt breaks axisymmetry to give n ≠ 0 forcing
[[ForcingTerms.coil_set]]
source = "pf_hoop"
radius = 1.8
height = 0.9
currents = [5e3]
tiltx = [2.0]

# Analytic window-pane array, by two opposite [R, Z] corners ...
[[ForcingTerms.coil_set]]
source = "window_pane"
n_coils = 8
rz_corners = [[2.2, -0.6], [2.2, 0.6]]
gap_fraction = 0.15
currents = [1e3, -1e3, 1e3, -1e3, 1e3, -1e3, 1e3, -1e3]

# ... or by standoff off the plasma surface at a poloidal angle (degrees)
[[ForcingTerms.coil_set]]
source = "window_pane"
n_coils = 2
standoff = 0.25
poloidal_angle = 0.0
poloidal_length = 1.2
poloidal_tilt = 0.0
gap_fraction = 0.15
currents = [1e4, -1e4]

# Analytic helical array on a circular torus, pitch m_hel/n_hel
[[ForcingTerms.coil_set]]
source = "helical"
R0 = 1.7
a = 0.6
m_hel = 4
n_hel = 1
n_coils = 4
currents = [1e3, 1e3, 1e3, 1e3]

A coil HDF5 file stores one subgroup per coil set under a parent group (default coils): <group>/<set>/x, y, z as ncoil × s × nsec Cartesian metres, an optional currents dataset, and the winding multiplier as the attribute nw; convert_coil_dat_to_h5 and convert_coil_h5_to_dat translate the ASCII format, read_coil_h5 and write_coil_h5 read and write it.

The field is linear in the coils, so a CoilForcingGrid built once per equilibrium and n evaluates coil sets one at a time, for comparing coil variants against one plasma without re-sampling the boundary:

forcing_grid = CoilForcingGrid(equil, cfg, n; psi=ffs.psilim)
spectra = [coil_forcing_modes(cs, forcing_grid, n, m_low, m_high) for cs in coil_sets]

Outputs

The applied spectrum is written with the response: PerturbedEquilibrium/ForcingModes/ (m, n, amplitude) and the control-surface spectra PerturbedEquilibrium/forcing_b, forcing_b_root_area and forcing_b_area (see Perturbed Equilibrium). A forcing file is captured raw with its tag under Input/RawInputs/ForcingTerms/, and the coil geometry as used, after shifts and tilts, under Input/RawInputs/Coils/, so that main(["gpec.h5"]) can replay the run without the original files; see the Scripting API.

API reference

GeneralizedPerturbedEquilibrium.ForcingTerms.BoundaryGrid — Type
BoundaryGrid

Pre-computed plasma boundary grid for evaluating coil fields.

Fields

  • mtheta, nzeta: grid dimensions
  • R, Z: cylindrical coordinates [mtheta] (same for all ζ, axisymmetric)
  • phi_grid: base toroidal angle grid [nzeta] in radians = -helicity × 2π × j/nzeta
  • phi_offset: per-θ toroidal angle correction [mtheta] from SFL coordinates: ν(ψ, θ) scaled by -helicity, so the physical toroidal angle at (i, j) is phi_grid[j] + phi_offset[i], as Fortran's phi = -helicity*(2π*ζ + dphi(ψ,θ))
  • dR_dtheta, dZ_dtheta: poloidal derivatives w.r.t. unit-norm angle θnorm ∈ [0,1] `dRdtheta[i] = dR/dθnorm = 2π × dR/dθphys`

GeneralizedPerturbedEquilibrium.ForcingTerms.CoilSetConfig — Type
CoilSetConfig

Per-coil-set configuration from a [[ForcingTerms.coil_set]] TOML block.

A coil set comes from one of several sources, selected by source:

  • "" or "file": read a geometry file — .dat (legacy ASCII) or .h5 (modern), chosen by extension. The file path comes from dat_file/h5_file or the machine+name convention.
  • "pf_hoop": an analytic horizontal circular loop (radius, height).
  • "window_pane": an analytic rectangular picture-frame array, placed EITHER by explicit corners (rz_corners) OR by physical standoff from the plasma surface (standoff, poloidal_angle, poloidal_length, poloidal_tilt); shared toroidal layout via n_coils, gap_fraction, phi0.
  • "helical": an analytic helical array on a circular cross-section torus (R0, a, m_hel, n_hel, theta_lo, theta_hi, n_coils, gap_fraction, phi0, offset).

Shifts/tilts apply to every source (the analytic geometry is built first, then transformed).

Fields

  • name: coil set name; resolves to {dat_dir}/{machine}_{name}.dat, or selects a set by name from a multi-set .h5 file
  • source: coil source discriminator (see above); empty/"file" reads a geometry file
  • dat_file: explicit path to .dat file (overrides machine+name convention)
  • h5_file: explicit path to .h5 file (multi-set; name selects which set, else the sole set)
  • currents: current [A] per conductor [ncoil]; shorter arrays pad with zeros
  • shiftx, shifty, shiftz: per-conductor translation [m] [ncoil]
  • tiltx, tilty, tiltz: per-conductor tilt in degrees (or meters if tilt_in_meters)
  • rotation_center_x, rotation_center_y, rotation_center_z: explicit rotation center [m]; defaults to arc-length-weighted center of mass
  • n_tilt: toroidal mode number for tilt/shift modulation; -1 means inherit run's n
  • tilt_in_meters: interpret tilt as displacement [m] instead of angle [degrees]

Analytic-source parameters (used only for the matching source):

  • radius, height: PF hoop circle radius and Z height [m]
  • rz_corners: window-pane cross-section as two opposite [R, Z] corners in m (corner mode)
  • gap_fraction: toroidal gap between adjacent coils as a fraction of their spacing
  • phi0: toroidal angle offset of the first generated coil [rad]
  • R0, a: helical torus major radius and minor (circle) radius [m]
  • m_hel, n_hel: helical poloidal/toroidal mode numbers setting the pitch
  • theta_lo, theta_hi: helical poloidal extent in degrees; a full turn when theta_hi-theta_lo == 360
  • n_coils: number of coils in a generated window-pane or helical array
  • offset: helical coil radial offset from the torus surface [m]
  • points_per_coil: optional override of the generated point count per coil

Window-pane standoff placement (alternative to rz_corners; needs an equilibrium):

  • standoff: outward-normal distance from the control surface to the frame center [m]
  • poloidal_angle: cylindrical poloidal angle of the frame center, in degrees
  • poloidal_length: poloidal leg span (corner-to-corner) along the surface tangent [m]
  • poloidal_tilt: extra tilt of the legs in degrees; 0 means tangential to the surface

GeneralizedPerturbedEquilibrium.ForcingTerms.RMPField — Type
RMPField

Abstract supertype of every external-forcing description the scripting API accepts: a resonant-magnetic-perturbation field, described by where it comes from and how strongly it drives (a forcing-mode file, a coil set with currents, or a precomputed spectrum).

Nothing is read or computed at construction; the modes are materialized against an equilibrium when the perturbed-equilibrium stage runs, so one RMPField can drive several solves.

Construction

RMPField(path; format=..., scale=1.0, kwargs...)
RMPField(coil_sets::Vector{Dict{String,Any}}; scale=1.0, kwargs...)
RMPField(ctrl::ForcingTermsControl; scale=1.0)
RMPField(modes::Vector{ForcingMode}; scale=1.0)

The first form points at a forcing-mode file, format defaulting to "hdf5" for an .h5 or .hdf5 extension and "ascii" otherwise. The second form takes TOML-shaped coil blocks (the [[ForcingTerms.coil_set]] layout) and selects the coil format. Remaining kwargs are ForcingTermsControl fields. These three return a single-source leaf (RMPSource). The last form takes a control-surface spectrum computed elsewhere, already in the unit-norm Φ_x convention, and returns a spectrum-literal leaf (RMPSpectrum).

Algebra

+, - and multiplication by a real or complex scalar (a complex factor phase-rotates the perturbation) build lazy linear combinations. The response is linear in the forcing, so each term is materialized on the control surface and the mode amplitudes are summed.

nominal = RMPField("nominal_efc.dat")
weld_field = RMPField("weld_fields.h5"; scale=0.5)
total = 2.0 * nominal + weld_field       # lazy: records terms and weights, computes nothing
pe = perturbed_equilibrium(plasma_response(ffs), total)   # materializes each term, sums, drives PE

Physical amplitude lives in the forcing description (per-conductor currents for coils, ForcingMode.amplitude for files). scale is NOT a physical amplitude: it is the source's weight in a linear combination, applied uniformly to the materialized spectrum of every toroidal mode. A source that is not a scalar multiple of another needs its own description: a coil set with a failed conductor is nominal - failed_coil, not 0.9 * nominal.

GeneralizedPerturbedEquilibrium.ForcingTerms._segment_field — Method
_segment_field(rx, ry, rz, dlx, dly, dlz, len) -> (bx, by, bz)

Exact field of a straight unit-current filament segment of vector dl⃗ and length len, without the μ₀/4π prefactor, at displacement r⃗ from the segment start (Hanson & Hirshman 2002, Eq. 8). With ε = Rᵢ + Rf - L, the effective squared distance ρ² = 2RᵢRf ε / (Rᵢ + Rf) reduces to the perpendicular distance squared near the segment, so the contribution is zero for ρ² below `BIOTSAVARTMINDIST_SQ`.

GeneralizedPerturbedEquilibrium.ForcingTerms.coil_forcing_modes — Method
coil_forcing_modes(coil_sets, forcing_grid::CoilForcingGrid, n, m_low, m_high; verbose=false) -> Vector{ForcingMode}

Fourier mode amplitudes, in the unit-norm Φ_x convention, of the normal flux that coil_sets — a Vector{CoilSet} or a single CoilSet — drive on the boundary sampled by forcing_grid: threaded Biot-Savart at every observation point, projection onto the boundary normal, then the 2D decomposition for toroidal mode n and m_low:m_high. GeneralizedPerturbedEquilibrium.ForcingTerms.convert_forcing_normalization — Method
convert_forcing_normalization(modes, from_tag, equil, n, m_out; psi, mtheta) -> Vector{ForcingMode}

Convert ForcingMode amplitudes from from_tag normalization to the internal unit-norm convention (= Fortran Phi_x) that perturbed_equilibrium applies the plasma response to.

If from_tag == "sfl_flux_Wb", the user has provided amplitudes in the 2π-angle SFL-flux convention. These are scaled by (2π)² to reach unit-norm, keeping their harmonics.

If from_tag == "normal_field_T", the amplitudes represent Fourier modes of B·n̂ in Tesla (2π-angle convention). Conversion to unit-norm Phi_x:

  • Inverse-Fourier reconstruct B·n̂(θ) from every harmonic in the file
  • Multiply pointwise by the area weight J|∇ψ| (Equilibrium.compute_jac_delpsi)
  • Fourier transform onto every harmonic in m_out

This conversion is a mode-mixing operation because J|∇ψ| varies poloidally, so the flux has sidebands beyond the file's own harmonics; m_out should be the run's full range. Each output harmonic is an exact projection of the full product, so a file wider than m_out loses nothing. The θ grid is widened past mtheta when the harmonics would otherwise alias.

The file's spectrum is itself a truncation of the true field, and the missing harmonics would mix into m_out too. Following the last-coefficient rule of thumb for spectral series (Boyd, Chebyshev and Fourier Spectral Methods), the first missing harmonic is taken to be comparable to the last one kept, so the flux each edge harmonic drives estimates what the truncation loses. A warning is issued when that exceeds truncation_tol of the total flux. Files with fewer than three harmonics have no edge to judge and are not checked.

Arguments

  • modes: Vector{ForcingMode} of one toroidal mode n (not modified)
  • from_tag: source normalization — "normal_field_T", "sfl_flux_Wb", or "unit_flux" for modes already in the unit-norm Φ_x convention the response consumes (a run's materialized forcing, recorded for replay)
  • equil: PlasmaEquilibrium providing boundary geometry

GeneralizedPerturbedEquilibrium.ForcingTerms.fourier_decompose_bn — Method
fourier_decompose_bn(bn, grid, n, m_low, m_high) -> Vector{ForcingMode}

2D Fourier decompose bn[mtheta, nzeta] to extract mode amplitudes for toroidal mode number n and poloidal range m_low:m_high.

Coefficients are computed as: bmn = (2 / (mtheta × nzeta)) × Σ_{i,j} bn[i,j] × exp(-i(m×θᵢ - n×ζⱼ))

The factor 2 matches the GPEC/DCON convention for real signals where positive and negative m modes are related by conjugation.

When called after project_normal_flux!, the returned amplitudes are in unit-norm convention equal to Fortran Phi_x (T·m² per unit-norm cell).

GeneralizedPerturbedEquilibrium.ForcingTerms.make_window_pane — Method
make_window_pane(; ncoil, rz_corners, gap_fraction=0.0, phi0=0.0,
                   np_pol=20, np_tor=40, name="window_pane") -> CoilSet

Build an array of ncoil rectangular "picture-frame" (window-pane) saddle coils, evenly spaced toroidally. The two [R, Z] points in rz_corners are the endpoints of the poloidal legs; the legs run along the straight segment between them at the two toroidal edges of the coil, joined by toroidal arcs at each corner. For a vertical frame give the two corners the same R (legs run in Z); for a horizontal frame give them the same Z. Adjacent coils are separated by a toroidal gap of gap_fraction times their angular spacing; the first coil is centered at toroidal angle phi0 [rad].

Each coil is a closed loop with np_pol points per poloidal leg and np_tor per toroidal arc. Currents are zeroed; load_coil_sets fills them.

GeneralizedPerturbedEquilibrium.ForcingTerms.project_normal_flux! — Method
project_normal_flux!(bn, B_R, B_Z, grid)

Project the cylindrical magnetic field (BR, BZ) onto the plasma boundary normal direction ∇ψ and store in bn[mtheta, nzeta].

Computes the unit-norm flux element Phix per (θnorm, ζnorm) cell [T·m²]: bn(θnorm, ζnorm) = 2π × R(θnorm) × (BR × ∂Z/∂θnorm - BZ × ∂R/∂θnorm)

The 2π factor comes from the toroidal Jacobian ∂r/∂ζnorm = 2π·R·êφ in the cross-product ∂r/∂θnorm × ∂r/∂ζnorm. The derivatives dR/dθnorm and dZ/dθnorm are stored in grid.dR_dtheta and grid.dZ_dtheta (unit-norm convention from sample_boundary_grid).

The output matches Fortran GPEC's Phi_x convention directly (no extra factor needed).

Arguments

  • bn: output array [mtheta, nzeta]; overwritten in-place
  • B_R, B_Z: cylindrical field components, length mtheta × nzeta (flat, θ-major)
  • grid: pre-computed boundary geometry from sample_boundary_grid

GeneralizedPerturbedEquilibrium.ForcingTerms.reconstruct_bn — Method
reconstruct_bn(amplitudes, m_modes, n_modes; ntheta=256, nzeta=180, theta_range=(-pi, pi)) -> (; theta, zeta, bn)
reconstruct_bn(modes::AbstractVector{ForcingMode}; kwargs...) -> (; theta, zeta, bn)

Evaluate the real normal-flux pattern bn(θ, ζ) of a spectrum on an arbitrary angular grid, inverting the basis of fourier_decompose_bn:

bn(θ, ζ) = Re Σ_k amplitudes[k] × exp(+i(m_k×θ - n_k×ζ))

The real part rather than a sum over ±m is what the decomposition's factor of 2 already accounts for: each retained (m, n) stands for itself and its conjugate partner (-m, -n).

theta_range defaults to (-π, π) so the outboard midplane falls in the middle of a map rather than being cut in half at its edges. The grid is independent of the one the spectrum was measured on, so a coarse decomposition can still be drawn smoothly.

GeneralizedPerturbedEquilibrium.ForcingTerms.sample_boundary_grid — Method
sample_boundary_grid(equil, mtheta, nzeta; psi=equil.rzphi_xs[end]) -> BoundaryGrid

Evaluate the plasma geometry on a uniform mtheta × nzeta grid on the flux surface psi, from the equil.rzphi_rsquared, rzphi_offset and rzphi_nu splines. dR/dθnorm and dZ/dθnorm (θ_norm ∈ [0,1]) come from periodic cubic splines of R and Z.

The default psi is the outermost computed surface psihigh, the last knot of the geometry splines; ψN = 1 would extrapolate them and can drive `rzphirsquarednegative. The physical control surface ispsilim(Fortran evaluates the coil field there,fieldbspsi), which lies insidepsihighwhen edge truncation fires: passpsi = psilim` whenever a ForceFreeStates solve is at hand, as the production paths do.

Toroidal grid direction (Fortran GPEC convention): phi_j = -helicity × 2π × j/nzeta, with helicity = sign(Bt) × sign(Ip) from equil.params.bt_sign and equil.params.ip_sign.

GeneralizedPerturbedEquilibrium.ForcingTerms.surface_point_and_normal — Method
surface_point_and_normal(equil, theta_cyl; psi=equil.rzphi_xs[end]) -> (R, Z, nR, nZ)

Locate the control-surface point at cylindrical poloidal angle theta_cyl (radians) and return it with the outward unit normal (nR, nZ) in the R-Z plane.

The flux-surface splines are parametrized by the SFL angle theta_sfl, related to the cylindrical angle by theta_cyl = 2π*(theta_sfl + rzphi_offset(psi, theta_sfl)). Since the offset is a small smooth perturbation, theta_sfl is recovered by fixed-point iteration. The tangent is taken by central-differencing R(theta_sfl), Z(theta_sfl), and the normal (dZ/dθ, -dR/dθ) is normalized and oriented outward (positive dot with (R-ro, Z-zo)), matching the normal-flux convention of project_normal_flux!.
