Lede. This milestone sets up the project before any code changes. The project adds a modified Rutherford equation (MRE, the steady island-width equation for a neoclassical tearing mode, NTM) to the Julia GPEC code (Generalized Perturbed Equilibrium Code) and uses it to state seed-threshold and saturated island widths for SPARC and ARC. M0 locates the input files, draws the planned pipeline, and records what today's code returns for the quantities the MRE will consume. Those quantities are the tearing stability index Δ′, the Mercier index DI, the resistive-interchange index DR and the Glasser–Greene–Johnson coefficient H. They are computed on every n = 1–3 rational surface inside normalized poloidal flux ψN < 0.9 of both baselines. All checks pass. Both baselines were found and match their publications. DR < 0 on all 14 surfaces. The two Δ′ formalisms agree to 0.08 %. The Galerkin Δ′ matches Fortran RDCON's convention. Three findings need decisions. §2 asks you to confirm the input files and records that no random BOUQUET profile draws exist yet (card M0-D1). §3 shows that a conducting wall changes Δ′ much more than the choice of formalism does, and that today's Riccati path cannot run with a wall (card M0-D2). §4 shows that the linear-tearing gate in physics.md has a sign that makes favourable curvature destabilizing. It matters because the 2/1 surface has Δ′ > 0 on both machines (card M0-D3). M0-D1 and M0-D2 are needed by M5 and M0-D3 by M2. (Hand-off decisions D1–D7 in QUESTIONS.md are separate.) None blocks M1.

1. Orientation

The question. For the published SPARC and ARC baseline equilibria, how large must a seed island be before an NTM grows (the marginal width wm), how large does it then saturate (wsat), and how uncertain are both? How much stored energy do saturated islands cost?

The physics. In steady state the island full width w satisfies F(w) = 0, with F a sum of terms that physics.md §1 makes individually switchable. The terms are the classical drive Δ′(w), with the finite-pressure correction that depends on DI; the bootstrap-current drive, cut off below the transport threshold width wd; the curvature term, which is stabilizing when DR < 0; the ion-polarization term, which depends on the island rotation frequency ω; and an optional external drive from a vacuum island. The smallest root where F turns positive is wm and the largest where it turns negative is wsat (figure 1). Every term needs inputs that GPEC already computes: Δ′ from the ForceFreeStates (FFS) module, and DI, DR, H and the trapped fraction ft from its ResistEval geometry. M0 checks those inputs on the real equilibria.

Numerical scheme. M0 builds none. The run matrix behind §3 has 24 GPEC runs: 2 machines × n = 1, 2, 3 × 2 Δ′ formalisms × 2 edge conditions. The two formalisms are Riccati, the chunked-propagator boundary-value solve descended from STRIDE, and Galerkin, the singular finite-element solve descended from RDCON. The two edge conditions are free boundary with the vacuum response (vacuum) and a conducting wall at the integration edge ψlim (wall). Each run uses one n, an automatic radial grid, and truncation at the last rational surface plus 0.2/n, which gives ψlim = 0.978–0.995. All 72 surface rows lie inside ψN < 0.9 and are well clear of ψlim. The decks are written by reports/scripts/m0_make_decks.py into results/m0_current_behavior/.

4. The sign of the linear-tearing gate in physics.md §4

What is being done. physics.md §4 excludes a surface from root finding as "linearly tearing unstable" when Δ′mn > Δ′crit = √2 π3/2 DR/wd, citing Leuthold Eq. 4.1. M2 implements this gate.

The result. The rendered Eq. 4.1 (Leuthold JPP 2026 p. 10) reads Δeff = Δ′ − Δcrit = Δ′ − √2 π3/2 DR/wd. The same paragraph says that DR < 0 is favourable curvature and that the effect is modelled "by reducing the free energy available for a tearing mode (Δ′)". With DR < 0 and wd > 0, the printed Δcrit is negative, so Δeff is larger than Δ′: the printed formula makes the curvature destabilizing, opposite to the text. Leuthold's Fig. 6 and 7 show Δeff below Δ′, which matches the text, so the printed sign appears to be a typesetting slip. physics.md §4 copies it.

Why it matters here. DR < 0 on every surface (figure 3). The 2/1 surface has Δ′ > 0 on both machines (+2.64 SPARC, +3.49 ARC, table 2), and so does ARC 4/3 (+4.81). As written, the gate marks these surfaces, and every surface with Δ′ above a negative threshold, as linearly unstable with no roots. That would remove the 2/1 surface, which KR1 and KR3 are about. With the sign reversed, the gate subtracts a positive Δ′crit. Whether the 2/1 surfaces then pass depends on wd, which M1 computes.

What this does not settle. No wd has been computed yet, so I have not evaluated how far the 2/1 surfaces sit from the corrected threshold. The prefactor is also open: √2 π3/2 is the large-aspect-ratio form, while DR and Δ′ here are toroidal. I have not re-derived the threshold. Lütjens 2001, which Leuthold cites for it, is not in refs/. Fitzpatrick 2025 is, but I have not checked its derivation.

Decision M0-D3: sign of Δ′crit in the linear gate

Found. physics.md §4 and Leuthold Eq. 4.1 as printed give Δ′crit < 0 for favourable curvature, which contradicts Leuthold's own text and figures. Read that way, the gate excludes the Δ′ > 0 surfaces of both machines, including 2/1 (table 2).

Why it is your call. It changes physics.md, and it decides whether the 2/1 surfaces enter the KR1 analysis.

Confidence that the printed sign is a slip: high (the text, Fig. 6 and Fig. 7 all agree against it). Between (a) and (c): moderate preference for (a), because it keeps the gate the tearing-physics-suite cross-check uses.
